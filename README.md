# MagHacker
MagHacker är ett fusk för Magma (https://matteappen.se) som svarar alla rätt på alla frågor du får. Gratis att använda. Magma borde göra mig till developer för jag kan faktiskt säkerhet jämfört med de.
Koden är obfuskerad för att Magma ska ha det svårt att patcha.
